# Smart Campus Issue Tracking System

## About the Project

Smart Campus Issue Tracking System is a web-based application designed to help university students report and track campus-related issues efficiently. It allows staff members and administrators to manage reported issues through a centralized platform.

## Main Features

- User Registration and Login
- Role-Based Access Control
- Issue Reporting
- Issue Tracking
- Issue Assignment and Management
- Issue Status Updates
- Photo Evidence Upload
- Admin and Staff Management

## User Roles

- **Student:** Report and track issues.
- **Staff:** Manage assigned issues and update their status.
- **Admin:** Manage users and oversee the entire system.

## Technologies Used

### Frontend
- Vue.js
- Quasar Framework
- JavaScript
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Deployment
- Docker
- Nginx

## Project Structure

The project is maintained using separate Git branches:

- `main` – Project overview and documentation.
- `frontend` – Frontend implementation.
- `backend` – Backend implementation.

## Project Goal

To improve campus issue reporting, communication, and resolution through a centralized digital platform.
